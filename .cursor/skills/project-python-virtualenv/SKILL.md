# 项目 Python 虚拟环境路径

**video-subtitle-remover** 在 VideoWorkbench 布局中使用 **`{VIDEOBENCH_HOME}/envs/vsr`**。

安装：`{VIDEOBENCH_HOME}/bin/install.ps1`。便捷启动：仓库根 **`main.bat`** / **`gui.bat`**（调用 `bin/activate-vsr.cmd`）。
